# React Notes App 📝

A simple Notes App built using **React.js** that allows users to create, view, edit, and delete notes. It has a clean, dark-themed interface and a responsive layout.

Vist Here:
https://notes-space-fv2iidgva-akanksha10029s-projects.vercel.app/

## 🚀 Features

* **Add Notes:** Create notes with a heading and description.
* **View Notes:** Display all your saved notes in a card layout.
* **Edit Notes:** Update existing notes whenever needed.
* **Delete Notes:** Remove notes that are no longer required.
* **Notes Counter:** Keep track of the total number of notes.
* **Responsive Design:** Works on different screen sizes.

## 🛠️ Technologies Used

## 💻 Getting Started

Follow these steps to run the project on your local machine.

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project Folder

```bash
cd notes-app
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the application.
